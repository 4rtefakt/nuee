Your own model in R code

New model › type "R code (your own model)": a model you write in R, for what Nuée doesn't fit itself: anything R can fit (lm, glm, nls, mgcv, nlme, glmmTMB, unmarked, brms…), with the packages installed for the R Nuée uses (library() and package:: work as in R). Nuée gives the code its data, takes from the model what it can, and treats it like its other models.

  • General tab: the code editor (R in colour, line numbers; Ctrl+Enter fits) and its help, with an example made of the project's variables; Observations tab: the model's observations, as for the others (ticked, a condition).
  • The data: `donnees`, a data.frame of the model's observations, one column per variable of the project under its name (qualitative variables as factors, their categories in the project's order), then the observations' IDs, as text.
  • The model: the code's last value (lm(...), fit…), any R object. Or a list whose elements Nuée recognises: list(modele = fit, valeurs = c(density = 3.2, slope = -0.4), tableaux = list(counts = d)); `valeurs`, named numbers, key results that documents cite ({{M1.valeurs.density}}) and What changed follows; `tableaux`, named data.frames, shown and exported.
  • The code runs in an environment of its own, each expression in turn, as in the R console: a visible value is printed (a ggplot or lattice plot drawn), except the last, the model. What it prints, its messages, its warnings and its plots are kept. An error gives R's message and its line (the editor goes there); a package that isn't installed is named, with how to install it; the model stays in the dialog, not fitted.

From the model, each part when the object allows it: print(summary()); the coefficients (coef(summary()) when it is a table of numbers with a column of standard errors, found by its name (Std. Error, se(coef)…), or several, as glmmTMB's cond, zi and disp; an mgcv gam's from summary()$p.table, its parametric part, without the coefficients of its curves' bases, s(x).1…, its curves being in the summary; else coef() with the standard errors of vcov()) and their 95% interval (the t distribution at their degrees of freedom when their test is a t, else the normal); nobs(), logLik() and its degrees of freedom, AIC(), BIC(); fitted() and residuals(), each value matched to its observation by its name, the number of its row in donnees (lm, glm, gls… keep them, even when the code reorders donnees), or to none when the names aren't those numbers (lme, nls) or the code fitted the model on other data; predict(fit, newdata) when it works, on the response scale (type = "response", when the model knows it: a GLM's counts, not their log).

Views: Summary (the class, N, logLik, AIC, BIC, the versions of R and of the packages, the warnings, what the code printed, summary(), Edit the code), Coefficients (a plot and the table), Residuals (against the fitted values, and the normal QQ plot), Plots of the code, Values and tables, The code; Predictions. Model › Edit model (or Edit the code) opens the editor with the code: fitted again, the model keeps its name and its place. What changed, documents ({{M1.coef.x}}, {{M1.AIC}}, {{M1.N}}), Export, the report and Update the data as for the other models. Compare models compares its AIC with the regressions and R-code models of the same response, as it is, on the same observations, when Nuée can check that their likelihoods compare (lm, glm, glm.nb, nls, and nlme's lme and gls fitted by maximum likelihood); otherwise its AIC is shown with why it isn't compared (a model fitted by REML, a transformed response…). The Methods text says the model was fitted with its authors' own R code, with R's version and the packages the code loaded, their versions and their citations (citation()), which join a document's references. Export to R: the data as the other scripts have them, the code as it is written, then what Nuée shows of the model (summary, coefficients, likelihood, plots of the residuals); Nuée runs the script before writing it and says if it doesn't give the same numbers.

Trust: opening a file never runs code from it. Code written, or approved, on this computer by you runs; the code of a project from elsewhere (a colleague's, a shared folder, a version from GitHub or GitLab) that you haven't approved doesn't: its models stay not fitted, under a bar "This project has R code written by someone else (M7) — Show the code / Run it". Run it approves that code (Nuée keeps its fingerprint, a SHA-256, in your settings) and fits the models; changed elsewhere again, it asks again. The R engine itself refuses code nobody approved, whatever the path (opening, Update the data, merging, versions). An organisation can turn this type of model off (the DisableCustomCode policy).
