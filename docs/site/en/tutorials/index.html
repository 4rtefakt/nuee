Tutorials

Three studies followed from start to finish: the question, the data, Nuée's windows one after the other, how to read the results, and the Methods text. Each has its table to download.

  • Before-after with controls (BACI)

    Did removing a weir raise the density of young trout? Six stations over 14 years: the impact − control gap, the BACI mixed model and its conditions, the interaction read correctly, the adjusted means, the Methods text and Export to R.

  • PLS on spectra

    Predicting the organic carbon of soils from their near-infrared spectrum: the preprocessing (SNV, detrending), the number of components by cross-validation, VIP, observed against predicted, the permutation test, then predicting new samples.

  • Monitoring a population

    A skylark counted on 40 sites over 17 years: from Which analysis? to TRIM's indices and trend and its class, then the density from line transects (distance sampling), and a figure for the report.

Before you start

  • Install Nuée: version 1.0.0 or later.
  • The tutorials' data are simulated: they were made for the exercise by an R script, with a fixed seed; the script is next to each table. No result is to be cited as an observation.
  • The screenshots come from Nuée 1.0.0 in English (the French pages show the interface in French). They were taken in Nuée's browser version: the desktop application's window is the same, but for a few buttons (Download there becomes Choose where…).
  • The interface is in English and French (View › Language).
