Démarrer

Pour installer Nuée, double-cliquez sur « Nuee-Setup-<version>.exe » et suivez les étapes : pour vous seul (sans droits d'administrateur) ou pour tous les utilisateurs de l'ordinateur.

R est inclus. Nuée apparaît dans Paramètres › Applications › Applications installées, d'où on peut la désinstaller ; les projets et les réglages sont gardés.

Si Windows affiche « Windows a protégé votre ordinateur » (éditeur inconnu), cliquez sur « Informations complémentaires » puis « Exécuter quand même ».

Pour les services informatiques qui installent Nuée sur de nombreux ordinateurs (installation silencieuse, Intune, Configuration Manager, stratégies de groupe, recherche de mises à jour coupée) : le guide de déploiement, en anglais, https://github.com/4rtefakt/nuee/blob/main/docs/deploiement.md

Sous macOS, R est inclus aussi : ouvrez Nuee-<version>-arm64.dmg (Apple silicon, macOS 14 ou plus récent) ou Nuee-<version>-x64.dmg (Intel, macOS 13 ou plus récent) et faites glisser Nuée dans Applications. La première fois, macOS dit qu'il n'a pas pu vérifier l'application (elle n'est pas signée par Apple) : cliquez sur « OK », puis sur « Ouvrir quand même » dans Réglages Système › Confidentialité et sécurité, et confirmez. Les réglages sont dans ~/Library/Application Support/Nuee.

Sous Linux, Nuée utilise le R de l'ordinateur.

  • Debian, Ubuntu et dérivées : sudo apt install ./Nuee-<version>-amd64.deb installe aussi R et les paquets R nécessaires. Nuée apparaît dans le menu des applications.
  • Autres distributions : Nuee-<version>-x86_64.AppImage (le rendre exécutable, puis le lancer) ou Nuee-<version>-x64.tar.gz (le décompresser, puis lancer ./nuee). Installer d'abord R, puis dans R : install.packages(c("httpuv", "jsonlite", "openxlsx", "haven", "readxl", "foreign", "nlme", "mgcv", "MASS", "rpart", "cluster", "RSQLite", "ranger")).

Les projets .usp demandent python3. Pour un autre R que celui du PATH : Fichier › Réglages... (voir Le R utilisé par Nuée), ou lancer Nuée avec RSCRIPT=/chemin/vers/Rscript. Les réglages sont dans ~/.config/Nuee.

Ouvrir

Fichier › Ouvrir (Ctrl+O) :

  • un projet .usp : données, modèles et résultats enregistrés dans le fichier ;
  • un projet enregistré par l'application (.nuee ; .json pour les versions avant 0.9.1) ;

  • un tableau, une ligne par observation :

    Excel .xlsx, .xlsm, .xls        texte .csv, .txt, .tsv (séparateur, virgule décimale et
R .rds, .RData                    encodage reconnus, y compris le « texte Unicode »
SPSS .sav, .zsav, .por            d'Excel)
Stata .dta                      SAS .sas7bdat, .xpt
jamovi .omv                     dBase .dbf, Weka .arff
spectres JCAMP-DX .jdx, .dx, .jcm et SPC .spc (voir Spectres)
GeoPackage .gpkg (une couche de QGIS : voir Cartes et données spatiales)

    Un export de KoboToolbox ou d'ODK Central (.xlsx, .csv, ou le .zip d'ODK) est reconnu à ses colonnes et s'ouvre par son import (voir Données de terrain de KoboToolbox ou d'ODK).

    La première colonne sert de nom d'observation si c'est du texte ou si elle s'appelle « ID », « Obs », « Nom »... (pour un fichier R, les noms des lignes) ; les autres colonnes de texte dont toutes les valeurs diffèrent (un code par observation) deviennent des identifiants secondaires : elles servent d'étiquettes mais n'entrent pas dans les modèles ; les autres colonnes de texte, les facteurs R et les variables étiquetées de SPSS ou Stata sont des variables qualitatives (dans l'ordre de leurs modalités). Pour un classeur à plusieurs feuilles ou un fichier R à plusieurs tableaux, l'application demande lequel ouvrir. Une colonne de mesures qui a quelques cellules de texte (<0,5, <LOD, nd, n.d., #N/A...) reste une variable quantitative : ces cellules sont lues comme manquantes, et la barre d'état dit combien, dans quelles variables (dont celles sous la limite de détection). Les dates et heures d'Excel restent des dates (2024-05-03), en texte, comme celles d'un fichier texte (telles qu'écrites : 14/05/2019) ou de R : une colonne de dates est une variable qualitative quand des dates reviennent (des secteurs comptés le même jour), un identifiant secondaire quand toutes diffèrent, le nom des observations si c'est la première colonne (la mettre alors plus loin pour en faire un temps) ; variable ou identifiant, elle peut être le temps (voir Le temps en dates). Un nombre d'Excel sans format de date (43599) reste un nombre. Un fichier texte dont une ligne a plus de valeurs que l'en-tête est refusé, avec le numéro de la ligne, plutôt que de décaler les colonnes. Un fichier R doit contenir des tableaux ; tout autre objet est refusé. Les fichiers R ne s'ouvrent qu'avec R 4.4 ou plus récent (celui de Windows) : avec un R plus ancien, comme celui d'Ubuntu 22.04 ou 24.04 ou de Debian 12, un .rds ou un .RData pourrait exécuter du code dès sa lecture (CVE-2024-27322) ; Nuée le refuse donc : enregistrez le tableau en CSV ou en Excel.

Fichier › Coller un tableau (Ctrl+V) : des cellules copiées dans Excel, LibreOffice, Google Sheets ou jamovi deviennent un projet (la première ligne donne les noms des variables). Le projet n'a pas encore de fichier : l'enregistrer (Ctrl+S).

Fichier › Importer depuis KoboToolbox ou ODK... : les relevés sur téléphone exportés par KoboToolbox ou ODK Central (voir Données de terrain de KoboToolbox ou d'ODK).

Fichier › Importer des spectres : des fichiers de spectres réunis en un projet (voir Spectres). Déposer des fichiers sur la fenêtre (glisser-déposer depuis l'Explorateur) les ouvre de même : des spectres JCAMP-DX ou SPC ensemble font un seul projet, comme Importer des spectres ; les autres fichiers s'ouvrent chacun comme avec Fichier › Ouvrir. Un double-clic sur un projet .nuee dans l'Explorateur Windows l'ouvre dans Nuée (dans la fenêtre déjà ouverte s'il y en a une). Les derniers fichiers ouverts sont dans Fichier › Ouvrir un fichier récent.

Pour essayer, Aide › Projets d'exemple :

  • Pommes : 120 pommes inventées (quatre variétés, culture bio ou conventionnelle, une douzaine de mesures et une note de dégustation) avec quatre modèles prêts : une ACP, une PLS de la note, une PLS-DA des variétés et une OPLS-DA de la culture. Le tableau d'origine, vergers.csv, est à côté (resources\exemple) pour essayer l'ouverture d'un tableau.
  • Suivi d'alouettes : les deux projets du tutoriel de suivi, une alouette comptée sur 40 sites pendant 17 ans (TRIM et un modèle mixte binomial négatif, ajustés) et ses transects linéaires (échantillonnage par distances : densité et effectif).
  • Un seuil arasé : les jeunes truites du tutoriel BACI, avant et après l'arasement d'un seuil, avec la vue avant/après des Tests statistiques et son modèle mixte.

Leurs données sont inventées ou simulées (les tableaux des tutoriels se téléchargent sur le site de documentation). Chacun s'ouvre en projet nouveau, ses modèles ajustés et ses vues ouvertes ; Enregistrer demande où le ranger. Quand un projet des alouettes ou des truites est devant, la barre d'état donne le lien de son tutoriel.

Enregistrer et retrouver son travail

Fichier › Enregistrer (Ctrl+S) écrit le projet (.nuee) avec ses données, ses modèles et la séance en cours : modèles calculés, panneaux ouverts et leur disposition, réglages des graphiques (axes, couleurs, étiquettes, titres), sélections, choix des VIP, groupes du dendrogramme. En rouvrant le projet, les modèles sont recalculés et tout revient en place.

Le projet est écrit dans un fichier à côté, qui prend ensuite la place de l'ancien : une coupure du réseau ou un disque plein pendant l'enregistrement laisse l'ancien intact. Si un autre programme garde le fichier ouvert (synchronisation, antivirus), Nuée réessaie pendant cinq secondes, puis le laisse tel quel et le dit : enregistrer de nouveau, ou Enregistrer sous.... Si le fichier a été modifié ailleurs depuis qu'on l'a ouvert ou enregistré (un collègue, sur un dossier partagé ; une autre fenêtre), Nuée le dit et propose de réunir ses changements avec les vôtres (voir Travailler à plusieurs), Écraser, Enregistrer sous... ou Annuler ; pour un projet repris après un arrêt inattendu, Enregistrer sous..., Écraser ou Annuler. Le fichier dit aussi quelle version de Nuée et de R l'a écrit, et le nom de qui l'a enregistré ; un projet enregistré par une version plus récente de Nuée est signalé à l'ouverture. Nuée garde aussi d'elle-même des versions de chaque projet enregistré, pour y revenir : voir Historique et versions.

Rouvrir un fichier déjà ouvert (fichier récent, double-clic dans l'Explorateur) montre le projet ouvert au lieu d'en ouvrir une seconde copie.

En fermant l'application avec des changements non enregistrés, elle propose « Enregistrer et fermer ». Toutes les deux minutes, elle garde aussi une copie de secours des projets non enregistrés : si elle s'arrête sans avoir été fermée (panne, coupure), elle propose au lancement suivant de les récupérer. Fermer cette question sans répondre garde les copies pour la fois suivante ; seul « Ignorer » les efface.

Fichier › Réglages... › Au démarrage, « Rouvrir les projets ouverts quand Nuée a été fermée » : au lancement suivant, les projets enregistrés (.nuee) ouverts quand Nuée a été fermée reviennent, avec leurs modèles et leurs vues ; un fichier déplacé ou supprimé depuis est nommé dans la barre d'état. Sans cette case, la page d'accueil propose Rouvrir la dernière séance. Après un arrêt inattendu, ce sont les copies de secours qui sont proposées.

Édition › Annuler (Ctrl+Z) revient sur la dernière modification des données d'un projet (valeur modifiée, nouvelle variable, classe, scores en variables, définition supprimée...), jusqu'à 20 en arrière. Les modèles ajustés depuis restent, et un modèle modifié depuis (ajusté de nouveau avec d'autres réglages, ses notes) garde sa nouvelle définition ; celui qui lit ce qu'Annuler retire (une variable faite par le changement) part avec lui ou, s'il était là avant le changement, revient tel qu'il était. Édition › Rétablir (Ctrl+Y ou Ctrl+Maj+Z) refait, tel qu'il était, ce qu'Annuler a défait : une mise à jour des données avec sa source et ses étapes, les modèles ajustés à nouveau sur ses données. Les deux disent le changement qu'ils visent ; tout nouveau changement vide Rétablir.

Notes : le résumé de chaque modèle a une zone de notes, enregistrée avec le projet et reprise dans le rapport ; un crayon le signale dans l'explorateur.

Retirer un modèle (Modèle › Supprimer le modèle) demande confirmation. Sa définition reste dans le projet ; pour un modèle fait dans l'application, une case permet de la supprimer aussi (annulable).

Si le moteur R s'arrête

Les longs calculs se font en arrière-plan, dans un second R : pendant qu'un modèle s'ajuste, que des permutations tournent ou qu'une simulation avance, le reste de la fenêtre répond — les vues des autres modèles, les autres projets, les données, les menus. Le dialogue Nouveau modèle se met de côté quand l'ajustement dure plus d'un instant ; les vues du modèle s'ouvrent une fois qu'il est là, et si l'ajustement échoue, le dialogue revient avec ses réglages et l'erreur. Un changement du projet en calcul (une variable renommée, un modèle réajusté) attend la fin du calcul, puis se fait.

Un calcul qui dure plus d'une seconde et demie se montre dans la barre d'état, avec Arrêter (au-dessus d'un dialogue aussi) : une barre avec l'étape en cours — « Permutation 420 sur 999 », « Validation croisée : groupe 3 sur 7 » — et le temps qui reste, ou, pour un calcul qui ne compte pas ses tours (un ajustement seul), une barre qui passe et repasse avec le temps depuis son début ; une vue qui l'attend montre la même barre. Arrêter l'interrompt entre deux de ses tours, et rien ne change : le modèle ne s'ajoute pas, les données ne changent pas, la vue dit « Calcul arrêté ». Les longues boucles s'arrêtent ainsi : les permutations (d'une PLS, d'une PERMANOVA, d'un test de dispersion, du test de Mantel et de son corrélogramme, des espèces indicatrices, des tests d'une RDA, des variables ajustées aux axes d'une ordination, de l'I de Moran), les modèles de la sélection par l'AIC, les départs aléatoires d'un NMDS, les simulations de la puissance, les tours des validations croisées (ACP, PLS, OPLS, modèles linéaires, GAM, arbres, forêts aléatoires, arbres boostés), les arbres boostés arbre par arbre, les tirages de la stabilité d'un arbre, la sélection pas à pas des points de changement de TRIM, les intervalles d'iPLS, Un modèle par réponse, le choix de k des k-moyennes, et les étapes que rejouent Mettre à jour les données et le retrait d'une étape. Un calcul qui ne s'arrête pas entre deux tours — un ajustement seul en code compilé (un modèle mixte, un GAM, les arbres d'une forêt aléatoire, l'échantillonnage par distances, l'estimation de TRIM) ou le code d'un modèle de code R — s'arrête tout de même une seconde et demie plus tard : son R est arrêté, un autre prend sa place, et le projet est tel qu'il était. Le code de la console R se fait dans le R de la fenêtre et ne s'arrête qu'à sa fin ; Arrêter le dit alors, et Aide › Redémarrer le moteur R reste. Pendant Mettre à jour les données, son propre Arrêter interrompt aussi le modèle en train d'être ajusté. L'application signale l'arrêt du moteur et propose de le redémarrer ; on peut aussi le faire soi-même (Aide › Redémarrer le moteur R) si un calcul ne finit pas. Les projets se rouvrent avec leurs modèles et leurs vues, depuis leur copie de secours s'ils avaient des changements, sinon depuis le fichier où ils s'enregistrent ; les changements faits depuis la dernière copie de secours (deux minutes au plus) sont perdus. Fermer Nuée quand le moteur ne répond plus garde les copies de secours, proposées au lancement suivant. Au-delà d'une minute de calcul, la barre d'état le rappelle.

Aide › Quoi de neuf : les nouveautés de chaque version (affichées une fois après une mise à jour). La version installée (Nuee-Setup, l'application macOS ou les paquets Linux) cherche au démarrage s'il existe une nouvelle version (une seule demande à GitHub, rien d'autre n'est envoyé) et la signale dans la barre d'état ; sous macOS et Linux, un clic ouvre la page de la version. Sous Windows, un clic propose de mettre à jour : le programme d'installation est téléchargé et vérifié (son empreinte SHA-256 doit être celle que donne GitHub), puis Nuée se ferme (en proposant d'enregistrer les projets modifiés), l'installe et redémarre. Pour une installation pour tous les utilisateurs, Windows demande l'autorisation. Aide › Chercher une mise à jour fait de même à tout moment, même sans la recherche au démarrage ; Aide › Chercher une nouvelle version au démarrage arrête la recherche.

Le R utilisé par Nuée

Fichier › Réglages... : Nuée calcule avec son propre R (sous Windows et macOS, R 4.6.2 avec tous les paquets qu'il lui faut), le choix recommandé, ou avec un R déjà installé sur l'ordinateur, en version 4.3 ou plus récente. La liste montre ceux que les installateurs de R mettent aux endroits habituels : sous Windows, ceux que connaît le registre et ceux de Program Files ou de votre propre dossier Programs ; sous macOS, celui du CRAN et celui de Homebrew ; sous Linux, où Nuée prend par défaut le R de l'ordinateur trouvé dans le PATH, ceux de /opt/R. Parcourir... en ajoute un autre, par son dossier.

Nuée lance une fois le R choisi pour le vérifier : sa version, et les paquets dont le moteur a besoin (httpuv, jsonlite, openxlsx, haven, readxl, RSQLite et ranger, et mgcv, nlme, MASS, rpart, cluster et foreign, parmi les paquets recommandés de R). « Les installer » installe ceux qui manquent depuis le CRAN, dans la bibliothèque de l'utilisateur de ce R, créée au besoin, en montrant ce que dit R pendant ce temps ; ou copiez la ligne affichée et lancez-la dans ce R (R ou RStudio). Avec un R antérieur à 4.4, les fichiers .rds et .RData ne s'ouvrent pas ; antérieur à 4.5, les empreintes des fichiers de données sont des MD5 et non des SHA-256 (voir Étapes des données et mise à jour).

Le bouton « Utiliser ce R » redémarre le moteur avec lui, et les projets ouverts se rouvrent avec leurs modèles, leurs vues et leurs changements (« Au prochain démarrage » attend). Les paquets et le .Renviron de ce R s'appliquent, pas votre .Rprofile, pour qu'il ne change pas les résultats. Si le R choisi ne démarre pas (supprimé, abîmé), Nuée calcule avec son propre R et le dit une fois. Une organisation peut choisir le R de tous ; les Réglages le montrent alors, sans le changer. Aide › Informations de diagnostic et Aide › À propos disent quel R est utilisé.

L'explorateur (à gauche)

Projets, données, modèles importés d'un fichier .usp, modèles calculés et leurs vues.

Double-clic : ouvrir. Clic droit : toutes les actions (calculer, modifier, ajouter ou retirer une composante, exporter, supprimer...). Double-cliquer un modèle importé le recalcule en R ; le Résumé marque chaque valeur : « = » identique à la valeur enregistrée dans le fichier, « ≈ » proche (moins de 0,01), « ≠ » différente. Le Q2 diffère en général : un modèle importé est validé comme les autres (voir « Validation croisée ») ; « Centres et poids du modèle complet » redonne celui du fichier.

L'explorateur suit le travail : un projet ouvert, ou un modèle ajusté, vient en vue en haut, et ouvrir un projet replie les modèles ajustés des autres projets, une ligne chacun (leur flèche les déplie).

Menus et barre d'outils

Fichier, Édition, Modèle, Graphiques, Prédiction, Fenêtre, Affichage, Aide. Raccourcis :

Ctrl+O ouvrir            Ctrl+S enregistrer         Ctrl+E exporter les résultats
Ctrl+V coller un tableau Ctrl+Z annuler             Ctrl+H chercher et remplacer
Ctrl+Y (ou Ctrl+Maj+Z) rétablir
Ctrl+K rechercher une commande    Ctrl+J console R  Ctrl+C copier le tableau
Ctrl+N nouveau modèle    Ctrl+M modifier le modèle  Ctrl+= / Ctrl+- composantes
Échap  effacer la sélection    Ctrl+Suppr exclure la sélection et réajuster
Ctrl+Maj+N nouvelle fenêtre    Ctrl+Maj+D détacher le panneau   Ctrl+W fermer le panneau
Ctrl+B explorateur       F1 guide
Ctrl+Tab / Ctrl+Maj+Tab onglet suivant / précédent  F6 / Maj+F6 zone suivante / précédente

Affichage : thème sombre, français / anglais, taille du texte.

Les vues de la barre d'outils suivent le modèle devant : une ACP, une PLS ou une OPLS a celles de SIMCA (Résumé, Scores, Loadings, DModX, T², Contrib., VIP, Coeff., Obs/préd., HCA, comme toujours) ; une régression ou une autre analyse a les siennes (Coefficients, Effets, Résidus, Sélection par AIC... d'une régression ; Indices et Totaux de TRIM ; Détection et Densité de l'échantillonnage par distances). Le menu Graphiques commence par les vues du modèle actif ; celles qu'il n'a pas sont sous Graphiques › Autres graphiques.

Aide › Guide d'utilisation (F1) : ce guide, dans un panneau à droite de la fenêtre, à côté du travail, à la section de ce qui est devant : le type du modèle, la vue (F1 sur un modèle TRIM ouvre la section de TRIM, sur Graphiques › Sélection par AIC son paragraphe). Son sommaire, les sections d'avant et d'après, et une recherche dans toutes les sections (sans compter accents ni majuscules, les mots trouvés marqués) ; les sections qu'il cite (« voir Validation croisée ») et les adresses web sont des liens. Il reste ouvert pendant le travail, comme un autre panneau (Ctrl+W le ferme, F1 de nouveau va à ce qui est devant) ; ses boutons ouvrent le guide en ligne et en fichier texte.

Clavier et lecteurs d'écran : Alt (ou F10) mène à la barre de menus, les flèches dans ses menus, Entrée lance une commande, Échap revient ; Alt et la lettre soulignée d'un menu l'ouvre (Alt+F Fichier...). F6 va de zone en zone (barre d'outils, explorateur, chaque groupe de panneaux, barre d'état), Ctrl+Tab d'onglet en onglet ; sur un onglet, les flèches et Suppr. L'explorateur est un arbre (flèches ; Entrée ouvre, Espace choisit), un tableau une grille (flèches ; Entrée ou F2 modifie une cellule, Espace choisit une ligne, Entrée sur un en-tête trie). Maj+F10 ou la touche menu donne le menu de ce qui a le clavier (nœud, ligne, colonne, onglet, graphique). Un graphique est nommé par ce qu'il montre pour les lecteurs d'écran, et Ctrl+C copie ses nombres en tableau. Les dialogues gardent le clavier jusqu'à leur fermeture.

Les deux thèmes respectent les contrastes WCAG AA et le réglage « réduire les animations » du système ; Mise en forme › Couleurs « lisibles par les daltoniens » (Okabe-Ito) est faite pour les déficiences de la vision des couleurs, et les couleurs par défaut restent distinctes pour elles aussi.

Fenêtres

Au centre, un onglet par modèle (« M1 · PLS »), et un onglet pour chaque vue du projet (Données, Statistiques des variables, Historique). Avec plusieurs projets ouverts, l'onglet d'un modèle, et la barre d'état, commencent par le nom de son projet (« comptages_alouette · M1 · TRIM »). L'onglet d'un modèle est sa page : son résumé à gauche, ses scores et ses loadings à droite ; ses autres vues (VIP, DModX...) s'y ajoutent en onglets. Choisir un modèle dans l'explorateur affiche sa page ; fermer la dernière vue d'une page ferme la page.

Dans une page comme au centre, les vues se déplacent par leur onglet (glisser-déposer), se divisent et s'empilent ; glisser l'onglet d'un modèle à côté d'un autre permet de comparer deux modèles. Clic droit sur un onglet, ou l'icône en haut à droite d'un groupe : détacher dans sa propre fenêtre (par exemple sur un second écran), agrandir, fermer, fermer les autres, fermer tous les onglets de son projet, fermer toutes les vues. Fenêtre › Fermer toutes les vues ferme tous les onglets du centre, pages des modèles et vues des projets (l'explorateur et la console R restent).

Fenêtre › Nouvelle fenêtre ouvre une deuxième fenêtre complète. Une sélection d'observations (cadre ou lasso dans un graphique, clic sur un point ou une ligne de liste) apparaît dans toutes les vues et toutes les fenêtres du même modèle. Le titre d'une fenêtre, que montrent son bouton dans la barre des tâches et le menu Fenêtre, nomme le projet qui est devant : celui sur lequel agissent les menus.

Graphiques : molette pour zoomer ; clic droit pour copier l'image ou l'enregistrer (PNG, SVG), voir les contributions de la sélection ou en faire une classe.

Ctrl+C dans une vue qui montre un tableau (résumé, listes, statistiques...) copie le tableau en texte séparé par des tabulations, à coller dans Excel (une liste : toutes ses lignes, en pleine précision) ; avec du texte sélectionné, Ctrl+C copie le texte comme d'habitude.

Affichage › Rechercher une commande (Ctrl+K) : taper une partie du nom d'une commande ou de son menu (« vip », « exporter r »), ou d'une analyse, en français ou en anglais, ou son code (« trim », « glm », « nmds », « forêt aléatoire »), puis Entrée : la commande se lance, ou Nouveau modèle s'ouvre sur ce type.
